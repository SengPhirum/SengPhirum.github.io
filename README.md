# Phirum Seng — Personal site

A fast, single-page personal profile at [sengphirum.github.io](https://sengphirum.github.io/), built with semantic HTML, modern CSS, and a small amount of vanilla JavaScript.

## Highlights

- Responsive editorial-style profile for finance and technology work
- All public GitHub repositories loaded automatically from the GitHub API
- Project grouping by focus area, with topic/language filters, search, and sorting
- Live repository, star, and language statistics
- Accessible navigation, focus states, reduced-motion support, and graceful API fallback
- No framework, package install, or build step required

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
